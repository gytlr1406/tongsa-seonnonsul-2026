# 2026. 중등 서논술형 평가 도움자료 개발 - 고등학교 통합사회1·2

충청북도교육청 서·논술형 평가 도움자료 개발 고등학교 통합사회1·2 개발팀의 작업용 웹앱입니다.

- 개발 일정표: 2026년 10~12월 달력, 일정 추가·수정·삭제
- 개발/검토 배정: 팀원별 개발·검토 세트 수 입력
- 성취기준 배분: 통합사회1·2 성취기준 30개의 담당자 선택, 성취기준·해설·성취수준(A~E) 보기

입력 내용은 Google Apps Script 웹 앱(`apps-script/Code.gs`)에 저장됩니다. 주소는 `config.js`의 `apiUrl`에 넣습니다.

출처: 2022 개정 사회과 교육과정(교육부 고시 제2022-33호 [별책 7]), 한국교육과정평가원 「2022 개정 교육과정에 따른 고등학교 사회과 공통과목 성취수준 개발 연구」(CRC 2024-23).
